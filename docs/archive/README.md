# Archived documentation

These files describe earlier versions of GOOD and are kept for reference only.
The current documentation is the MkDocs site in `docs/` (build it with
`mkdocs serve`).

* `good_model_documentation.docx` (v1.1, June 2024) describes the previous
  class design (`opt_model.py`, `Generator`, `Solar`, `Wind`). Its data
  provenance material is carried into `docs/data.md`.
* `latex/` is the formulation written for GOOD 1.x. It is superseded by
  `docs/formulation.md`, which corrects the storage balance sign, the ramp
  constraint and the transmission limit index, and drops features that were
  never implemented.
* The PowerPoint files are presentation material from 2024-2025.
